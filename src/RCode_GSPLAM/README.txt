
This folder contains the R-Code for the manuscript:

"Consistent Effect Estimation in Generalised Sparse Partially Linear Additive Models"

There are several subfolders:

* The folder "1_main" contains several scripts implementing the method (the MCMC sampler, functions to create the DR/MMR/Eilers design matrices, prior scaling and plotting routines).
* The folder "2_simu" contains three subfolders with code and results for the simulation studies: 
- the first subfolder is for the basis comparison DRB vs. MMR vs. Eilers
- the second subfolder is for the comparison of NBPSS vs. mboost
- the third subfolder is for MCMC mixing comparison NBPSS vs. SSGL in the supplement
* The folder "3_application" contains the script for the real data application (Leukemia survival).
* The folder "4_other" contains scripts that were used to generate plots (e.g. for the plot of the effect decomposition or the DR basis functions).
